# Formwork Trainer

A free workout builder for iPhone. Tap the muscles you want to train, tick the equipment you have, and get a workout. Every exercise is demonstrated by an animated 3D mannequin with form guides and common-mistake demos.

**Open it:** https://nwatson0.github.io/formwork/ — then in Safari tap Share → Add to Home Screen. It runs full-screen and works offline after the first visit.

Built with [three.js](https://threejs.org) (MIT licence, see `THREE-LICENSE.txt`).
